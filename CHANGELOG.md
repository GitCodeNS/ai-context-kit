# Changelog

All notable changes to AIContextKit are documented here.

## 0.2.0 - Unreleased

- Added Context Protocol v2 normative specifications.
- Added repository dogfooding with a compact startup packet and automatic Codex entry.
- Added metadata, lifecycle, precedence, retrieval, privacy, and source-of-truth rules.
- Added zero-dependency context checks, indexing, status, synchronization, initialization, and adoption analysis.
- Converted software and research examples into complete validation fixtures.
- Added optional Codex, Claude, Cursor, and generic adapters.
- Added migration recovery, release gates, and security guidance.

## 0.1.0 - Draft

- Created the initial universal protocol, domains, templates, examples, and local context design.
