# Roadmap

## Phase 0: Repository Foundation

Status: completed.

Universal protocol, project structure, public positioning, license, contribution guidance, safety boundaries, domains, templates, and initial examples exist.

## Phase 1: Context Protocol v2

Status: completed.

- dogfood the full startup and lifecycle model;
- publish normative metadata, precedence, retrieval, and privacy contracts;
- add source-of-truth ownership;
- keep the Markdown core usable without tools.

## Phase 2: Assurance Tooling

Status: completed.

- validate metadata, references, budgets, lifecycle, and examples;
- generate a derived context index;
- provide safe dry-run initialization and read-only adoption analysis;
- maintain zero runtime dependencies.

## Phase 3: Compatibility And Fixtures

Status: completed.

- complete software and research fixtures;
- add optional Codex, Claude, Cursor, and generic adapters;
- add migration, conflict, budget, and security test scenarios.

## Phase 4: First Release

Status: active.

- pass `docs/RELEASE_CRITERIA.md`;
- finish security review and migration report;
- obtain user authorization for the first commit;
- obtain separate authorization before GitHub push.

## Later Possibilities

- packaged CLI after the file protocol stabilizes;
- more domain examples;
- documentation site;
- optional MCP integrations;
- empirical context-quality evaluations across assistant hosts.
