# Research Notes Example

This example shows how AIContextKit can be applied to a research or information-organization workspace.

The example focuses on context efficiency for source-heavy work. Instead of loading every paper, article, note, or transcript into the active chat, the AI assistant keeps a compact research context folder with source maps, claim/evidence tracking, open questions, and the current reading or writing task.

Start from `ai-context/AI_CONTEXT.md`, then adapt the source map and evidence files to the real research workspace.
