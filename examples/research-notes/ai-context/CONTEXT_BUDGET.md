# Research Context Budget

## Startup

Read the bootstrap, this budget, the retrieval index, and only the source notes selected for the current claim comparison.

## Avoid

- Loading the full source corpus.
- Treating notes as verified evidence.
- Copying long source passages into durable context.

## Expansion

Open original sources only to verify metadata, exact wording, methodology, or a disputed claim. Hand off when the research question changes or the source set no longer fits one comparison task.
